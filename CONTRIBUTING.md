# Contributing

Thank you for helping build TemporalFix. By participating, you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).

## Workflow

1. Open an issue for substantial behavior or public API changes.
2. Use a focused branch and Conventional Commit messages.
3. Add typed implementation and focused tests.
4. Run the relevant commands in [DEVELOPMENT.md](DEVELOPMENT.md).
5. Update documentation, changelog, decisions and limitations when applicable.
6. Open a pull request with observed test results and explicit skipped checks.

Do not include credentials, private data, model weights or datasets without
documented redistribution permission. Contributions are licensed under
Apache-2.0.
